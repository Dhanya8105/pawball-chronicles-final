# CV / embedding stack — implementations now live in pipelines/cv/ and

#
# Disk footprint note (learned from actually installing this during
# Milestone 3 development): torch's PyPI wheel bundles CUDA libraries and
# is ~800MB even for CPU-only usage; ultralytics' own dependency pins can
# trigger pip to resolve a SECOND torch install if installed in the same
# command without torch already present, doubling that footprint
# unnecessarily. Installing torch and torchvision first, then ultralytics
# with --no-deps plus its few genuinely-missing small deps, avoided this in
# practice. A production Docker build should pin a CPU-specific torch wheel
# (e.g. from a CPU-only extra index) to avoid the bundled CUDA libraries
# entirely, since this AI service's actual inference here is CPU-bound
# (CLIP zero-shot, YOLOv8n) unless deployed to a GPU host for image
# generation (see docs/architecture/03-ai-pipeline.md).
